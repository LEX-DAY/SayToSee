# CalltoCall

Лёгкое приложение для видеовстреч до 10 человек. Организатор создаёт комнату,
получает подписанную ссылку и отправляет её участникам. Для входа достаточно
указать имя.

Медиа передаётся через LiveKit SFU: компьютер организатора не становится
сервером и не ретранслирует потоки остальных участников. Включены adaptive
stream, simulcast и dynacast.

## Запуск

Требуется Node.js 22.13 или новее и проект в LiveKit Cloud либо собственный
LiveKit-сервер.

1. Скопируйте `.env.example` в `.env.local`.
2. Заполните `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`.
3. Выполните `npm install`, затем `npm run dev`.

## Что реализовано

- комната на 10 участников;
- подписанная инвайт-ссылка сроком на 24 часа;
- отдельные права организатора;
- камера, микрофон, демонстрация экрана и чат;
- адаптивная сетка участников;
- оптимизация трафика и нагрузки на слабых устройствах;
- русскоязычный адаптивный интерфейс;
- серверная выдача краткоживущих токенов без публикации API secret в браузере.
